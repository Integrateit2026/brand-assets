1 Start here

IntegrateIT Gate Integration turns standard Control4 relay outputs and contact sensors into a supervised driveway or access-gate experience. It drives a gate operator through open, close, and optional stop relays, tracks position from open and closed contacts, secures the opening with an unattended auto-close timer, and — most importantly — halts and reverses a gate that is closing when the safety loop reports an obstruction.

Ready for controlled commissioning. The package, Lua 5.1 runtime, Control4 relay and contact surfaces, output modes, state engine, auto-close timer, safety-loop reverse, license gate, persistence, and documentation pass automated QA. A qualified dealer must still complete a fresh install and an observed gate-cycle test on the target controller, relay hardware, operator, and safety devices.

What you get

  • Open, close, and optional stop relay outputs
  • Momentary pulse or latching output modes
  • Open and closed position-contact supervision with dealer-selectable polarity
  • An auto-close timer that re-secures the gate after a configured open interval
  • A safety-loop input that stops and reverses a gate mid-close
  • Travel-time endpoint estimation and a jam timeout when contacts are absent
  • Composer events, programming variables, diagnostics, persistence, and a license gate

2 Safety boundary

A moving gate can crush and kill. Keep the gate in view during commissioning. Never defeat the operator's own photo eyes, safety loops, force sensing, entrapment protection, or listed safety controls. This driver does not replace any operator safety function; its safety-loop reverse is an automation layer on top of, not a substitute for, the operator's own protection.

The relay outputs are only dry-contact commands to the installed gate operator. Before enabling control:

  1. Prove the operator and every safety device using the manufacturer's own controls.
  2. Confirm each Control4 relay is electrically isolated and rated for the operator input.
  3. Wire the safety-loop or photo-eye dry contact to the Safety Loop Input and confirm its active polarity.
  4. Observe a full open, stop, close, and obstruction-reverse cycle with the work area clear before handoff.

The Auto-Close timer closes the gate unattended. Only enable it when the operator's own warning devices and reversing safety are proven, and set the interval long enough for a vehicle to clear the opening.

3 Commission the gate

  1. Add IntegrateIT Gate Integration to the room that contains the gate.
  2. Bind the relay outputs: Open Output (1), Close Output (2), and, if the operator has one, Stop Output (3). Set Output Mode to match the operator interface.
  3. Bind the feedback inputs: Open Position Contact (4), Closed Position Contact (5), and Safety Loop Input (6). Set Contact Active State and Safety Loop Active State to match the wiring.
  4. Set Pulse Length for momentary operators and Travel Time to the real full-open travel time.
  5. Leave Auto-Close at zero for manual operation, or set a hold interval to secure the gate automatically.
  6. Run Print Diagnostic Summary and confirm the configuration reads back correctly.
  7. Clear the work area and observe open, stop, close, and a deliberate safety-loop obstruction during a close — the gate must reverse to open.
Start with the operator's documented pulse length. A longer pulse is not a substitute for correct wiring.

4Open Position ContactActive when the gate is fully open
5Closed Position ContactActive when the gate is fully closed
6Safety Loop InputActive when an obstruction is present in the gate path

Relay outputs energize with a CLOSE command and release with OPEN. In Momentary mode each output is pulsed for Pulse Length and then released; in Latching mode the direction output is held until the opposite direction or a Stop releases it. The driver always releases the opposite direction before energizing a new one (break-before-make).

5 Choose the output mode

ModeOutput behaviorTypical use
MomentaryEnergize, then release after Pulse LengthOperators with a step or dry-contact button input
LatchingHold the direction output until releasedOperators that require a maintained open or close contact

The optional Stop Output is always pulsed on a Stop command — even in Latching mode — and the open and close outputs are released first. A momentary Stop is deliberate: a latched Stop relay would stay held closed and inhibit every later open or close, so Stop never latches regardless of the Output Mode. If the operator has no stop input, leave binding 3 unbound and use Open or Close to change direction.

6 Understand position feedback

Position contacts are authoritative. Contact Active State selects the electrical state that means an endpoint is reached: Contact Closed means the circuit is active when closed; Contact Open means the circuit is active when open. When the open-position contact reports active, the gate is Open; when the closed-position contact reports active, the gate is Closed.

STATE_OPENED and STATE_CLOSED are the bind-time snapshots Director replays so state is correct at startup. They set the supervised state without firing transition events. Later live OPENED / CLOSED edges fire the matching event.

With no position contacts bound, the supervised state is estimated from Travel Time: a commanded open or close resolves to its endpoint after the configured travel time. When a position contact is bound, Travel Time doubles as a jam timeout — if the expected endpoint contact is not active when travel time elapses, the gate is marked Stopped and Last Error explains the jam.

A reboot does not preserve motion. A controller restart while the gate is opening or closing restores the state as Unknown rather than a stale Opening/Closing — no travel timer or relay drive survives a reboot — and the boot feedback poll, the next command, or a position-contact edge re-resolves the real position.

7 The safety loop

The Safety Loop Input is the driver's critical safety behavior. Safety Loop Active State selects the electrical state that means an obstruction is present (most loops break the circuit on detection, so the default is Contact Open).

  • While the gate is Closing, an active safety loop immediately releases the close output, drives the open output, fires Safety Loop Triggered and Gate Opening, and reverses the gate to open.
  • While the gate is not closing, an active safety loop fires Safety Loop Triggered and latches an obstruction flag; a subsequent Close Gate is refused until the loop clears.
  • A safety STATE_ bind snapshot latches the obstruction flag silently — it never reverses the gate or fires the event.

8 Auto-close

Set Auto-Close to zero for manual operation. When it is greater than zero and the gate reaches fully open, the driver fires Auto-Close Scheduled and starts a timer; when the timer elapses it issues a close (subject to the safety loop). Cancel Auto-Close or a Stop Gate cancels a pending auto-close without moving the gate. Reaching the closed position also clears any pending auto-close.

If the safety loop is active at the moment the auto-close fires, the close is refused and the gate stays open — an obstruction is never driven into. The auto-close automatically re-arms when the loop clears, so the gate still re-secures once the opening is clear. A re-asserting or bouncing open-position contact does not restart the countdown; only a genuine transition into fully open schedules a new auto-close.

12 Ownership, privacy, and licensing

This package is an original IntegrateIT implementation built on documented Control4 relay, contact-sensor, and driver contracts. It does not bundle another vendor's encrypted runtime, source code, brand assets, trial system, or license. Driver engineering, Control4 integration, documentation, QA, licensing, updates, and support are provided by IntegrateIT.

The gate runtime does not send gate state, customer identity, project identity, or Control4 credentials to a device vendor. The shared IntegrateIT license and update services use the controller identity, driver slug, version, configured license key, and update channel as documented in the reference below.

Lenient mode allows commissioning without an activated key and keeps License Status visible. Strict mode blocks all driver control until the Ops Portal has minted and validated a key for that controller. Installing this package does not itself mint or activate a controller license.

L Licensing

This driver is licensed per controller. Each license key locks to one controller's MAC address the first time it activates, exactly like other professional Control4 vendors.

  1. Generate a key for the customer in the IntegrateIT Ops Portal → Licenses.
  2. Paste it into the driver's License Key property in Composer.
  3. On activation the key binds to this controller; the License Status property shows Licensed.

Enforcement. License Enforcement defaults to Lenient (recommended): the driver works the moment it is wired, so you can stage and verify a job before a key is minted, and a paid site keeps running if the license server is ever unreachable. License Status still nags until a key activates. Set it to Strict to disable all control until a valid key binds.

Replaced the controller? Click Unbind in the Ops Portal. The next controller to activate with the key becomes its new home. The driver re-checks on boot and every 12 hours, and keeps working through brief internet outages (it re-validates when the relay is reachable again).

U Automatic updates

The driver checks IntegrateIT for a newer version on boot and once a day. There is no need to re-add the driver. When an update is available the Update Available property shows the new version and the driver fires its Update Available event.

  1. The driver flags Update Available: vX.Y.Z in its properties (or run the Check for Update Now action).
  2. Run the Download & Stage Update action. The new .c4z is fetched onto the controller.
  3. In Composer, right-click the device, then choose Update Driver. Your settings, bindings, and programming are preserved.
Tip: wire the Update Available event to a notification so you know the moment a new build ships.
