# Changelog — IntegrateIT JVC D-ILA Projector

## [0.2.0] - 2026-11-01
- LAN control: Control Method now offers RS-232, RS-232 + IR Power On, LAN, LAN + IR Power On and IR. LAN uses JVC's TCP 20554 handshake (PJ_OK, PJREQ, PJACK) per command, and Last Error names refused, silent, busy (PJ_NG) and password (PJNAK) cases. Existing RS-232 and IR projects keep their setting. A lens recall over LAN reports as sent, not as a No ACK, because the lens move outlasts the connection.
- IR Power On assist: the + IR Power On methods send JVC's discrete IR Power On with every Power On, so a projector whose port sleeps in standby (ECO Mode On) still turns on; everything else stays two-way. A quiet port in standby reads as a note, not an error. New Test IR action sends the Info key to prove the emitter, the IR binding and the Remote Code, and "Projector IR is not bound" stays in Last Error until the output is bound.
- Diagnosis: new Diagnose Link action and Link Diagnosis property print a verdict and a checklist, most likely cause first (port baud, binding, crossover cable, ECO Mode, Communication Terminal, Control4 setting). The driver also recognises and names echoes from a loopback plug or an echoing adapter. Counters restart at boot and on a Control Method change.
- Read-backs: ECO Mode (plus Set ECO Mode), input signal (Signal Present and Signal Lost events), anamorphic, aspect, lamp power and the projector's own remote code are read into properties and variables. If the projector's remote code differs from the Remote Code property, Last Error names both. Lamp Alert Hours fires a Lamp Hours Alert event once per threshold. It takes effect as soon as it is changed and survives restarts.
- Power reliability: a power command with no ACK is retried up to 4 times, 6 s apart. A command the projector ACKs but ignores is sent again after the 15 s grace window, even if Watch or Room Off is tapped again or alternated meanwhile. A Watch keeps its input through those retries. Power On from Unknown is sent even if the power query is not answered; Room Off from Unknown asks first. Set Picture Mode waits 10 s for its ACK. Warmup Time is now at least 25 s.
- IR only: an Unknown model no longer refuses commands. Power On and Standby are always sent, so a projector switched off with the JVC remote can be brought back. After a re-sent Power On, the input key is sent again when Warmup Time ends, so the input still lands. Cooldown counts from the confirming second Standby.
- Docs: the guide and catalog are rewritten for LAN, the IR assist, read-backs and Diagnose Link. Hardware claims the sources do not prove are hedged: Communication Terminal exclusivity, when Composer applies the serial settings, and Lamp On timing. Power On and Power Off events are documented as also firing when the state is relearned after a restart or a lost link. Correction to the 0.1.0 notes: declaring 19200 8N1 does not guarantee the bound port uses it, so check the port in Composer.

## [0.1.3] - 2026-10-30
- IR fallback: new Control Method property (RS-232 or IR). In IR mode the driver sends JVC's own remote codes (Code A 73 or B 63, JVC 16-bit format, Pronto patterns generated from and checked against JVC's published example) out of a new Projector IR connection: power, standby sent twice to confirm, HDMI 1/2, picture modes, lens memory 1-5, anamorphic, aspect, and every remote key. IR is one-way, so power is modeled with Warmup Time and a new Cooldown Time, inputs are assumed, and lamp power / lamp hours are refused with a reason. RS-232 behavior is unchanged.

## [0.1.2] - 2026-10-30
- Diagnostics for a projector that does not answer: JVC turns RS-232 off in standby when ECO Mode is on, so the guide and catalog now require ECO Mode Off, and Last Error says which link is broken - nothing ever received (ECO Mode, binding, crossover cable) versus bytes that are not JVC replies (baud or cable). New Serial Received property shows every byte in hex; new Serial Port property shows the Control4 binding state.

## [0.1.1] - 2026-10-30
- Fix: the projector showed as a blank row with no name in Composer's System Design tree. Composer draws the device tiles at 16 and 32 px and this build handed it a 300 px image (and pointed the proxy's small icon at it too), so the row rendered as an oversized blank smear. Tiles are now 16/32 px and the proxy carries the same image attributes as the bench-proven Xbox driver. No control changes.

## [0.1.0] - 2026-10-29
- Initial release: RS-232 control of JVC D-ILA projectors per JVC's published external-control protocol (19200 8N1, binary `21 89 01 … 0A` frames), built for the DLA-RS49U / RS4910 / X500R family (model code XHK1/XHK2). The projector joins the room through Control4's documented TV proxy as a video endpoint: Watch powers it on and selects HDMI 1 or HDMI 2, Room Off puts it in standby, and input changes from the JVC remote are reported back to the room.
- ACK pacing per JVC's spec: one command in flight, the next sent only after the ACK (and, for queries, the `@` response). Input switches wait up to 10 s and lens memory up to 30 s, because JVC ACKs those when the operation finishes.
- Power-state machine read from the projector: warmup is modeled (this generation reports Lamp On as soon as the lamp strikes), cooldown is read from the poll. Power On during cooling, Power Off during warmup, and input changes during warmup are held and released when the projector can accept them; a Watch during cooldown keeps its input. A 15 s grace window ignores one stale poll reply after a power ACK.
- Programming commands for picture mode, lens memory 1-5, anamorphic, aspect, lamp power, and Send Remote Key; lamp hours, picture mode, input, and model code read back into properties and variables; Remote Code A/B selectable for pass-through keys; Test Connection via JVC's null command.
- Silence handling: a command the projector ignores is reported as No ACK in Last Error; only power polls that draw no ACK count toward Projector Lost, so a projector that ACKs but holds answers while someone is in its menu stays Responding.
- Declares `<serialsettings>19200 8 none 1 none 232</serialsettings>` so the controller configures the bound port (factory gained the `serialSettings` manifest key for this).
- Pre-bench hardening: latest press wins against a power command already queued or awaiting its ACK (a queued one is cancelled, an in-flight one is followed by the held opposite); a source picked while a Power Off is in flight is held instead of dropped; a held power intent is cleared if its power command never gets an ACK; power commands wait up to 10 s for their ACK; an input switch the projector ignores (lamp still warming) is retried twice, 5 s apart, and cancelled by a newer input or Room Off.
