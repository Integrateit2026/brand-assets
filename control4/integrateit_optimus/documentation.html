1 Overview

Optimus AI brings a branded assistant, Service Requests, and a "My System" health view right into Control4 Navigator — on the phone app, iPad, T5, and Halo Touch — as a WebView experience served by the IntegrateIT relay.

The driver polls the relay outbound-only (no inbound ports), executes the actions the assistant decides on as Control4 events, and pushes device state + system health back to the relay so the customer's "My System" page stays live.

2 Install & setup

  1. Create the customer's site in the IntegrateIT Ops Portal → Site List; copy the Site ID and Site Token.
  2. Add this driver to the Family Room (or any always-on room). Set Relay URL, Site ID, and Site Token.
  3. Set the WebView address to https://relay.integrateit.dev/app/?site=<id>&token=<token> and add the experience button to Navigator.
  4. Bind the two garage-contact connections (301 / 302) if present, set Default Room ID for volume, and optionally a Camera Snapshot URL.
  5. Enter the License Key (see Licensing). Run Test Relay to confirm.
Sensitive actions (unlock, garage open) honor Allow Sensitive Actions and always require in-app confirmation.

L Licensing

This driver is licensed per controller. Each license key locks to one controller's MAC address the first time it activates, exactly like other professional Control4 vendors.

  1. Generate a key for the customer in the IntegrateIT Ops Portal → Licenses.
  2. Paste it into the driver's License Key property in Composer.
  3. On activation the key binds to this controller; the License Status property shows Licensed.

Enforcement. License Enforcement defaults to Lenient (recommended): the driver works the moment it is wired, so you can stage and verify a job before a key is minted, and a paid site keeps running if the license server is ever unreachable. License Status still nags until a key activates. Set it to Strict to disable all control until a valid key binds.

License StatusWhat it means
LicensedBound to this controller — activated.
Not activated — Lenient modeNo valid key yet. Control still works (Lenient); enter a key for production.
Bound elsewhereThe key is active on another controller. Unbind it in the Ops Portal to move it here.
Revoked / InvalidContact IntegrateIT. Under Strict enforcement control stays disabled until a valid key is entered.
Replaced the controller? Click Unbind in the Ops Portal — the next controller to activate with the key becomes its new home. The driver re-checks on boot and every 12 hours, and keeps working through brief internet outages (it re-validates when the relay is reachable again).

U Automatic updates

The driver checks IntegrateIT for a newer version on boot and once a day — no need to re-add the driver. When an update is available the Update Available property shows the new version and the driver fires its Update Available event.

  1. The driver flags Update Available: vX.Y.Z in its properties (or run the Check for Update Now action).
  2. Run the Download & Stage Update action — the new .c4z is fetched onto the controller.
  3. In Composer, right-click the device → Update Driver. Done. Your settings, bindings, and programming are preserved.
Tip: wire the Update Available event to a notification so you know the moment a new build ships.
