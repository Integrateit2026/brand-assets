1 Start here

IntegrateIT PlayStation 5 is a display-only Control4 AV source for a Sony PlayStation — a PS5 of any edition, and equally valid for a PS4 or any HDMI PlayStation. Its whole job is to put an HDMI OUT binding on the Connections graph so the console can be wired to a TV, AVR, or matrix input and selected as a source in Watch. One tap on the PlayStation tile and Control4 switches the room's video input and audio path to the console — which is exactly what a game console needs from the control system, and all this driver claims to do.

This driver drives nothing and reports nothing. There is no power, transport, or feedback path, by design. It is a labeled HDMI patch point, not a controllable device — the console is driven from its own controller, the way its makers intended.
Automated QA covers the rendered package — the AV binding classes, the flat Navigator icon ladder, the name-equals-filename law, and a clean lifecycle in the Control4 API simulator. A qualified dealer still confirms on real hardware that the room routes the feed and the source appears in Watch.

What you get

  • A satellite-class source proxy named PlayStation 5 that Composer lists as a selectable Watch source in every room it is visible in.
  • A single HDMI OUT AV binding (video + audio) to drop onto a TV, AVR, or matrix input.
  • A device-render icon — the console itself, floating on a transparent background like Control4's stock source icons — that renders in Composer and on OS3 Navigators, distinct at a glance from its Xbox sibling at every icon size, with an Icon Set property choosing between the floating art (default), a dark no-logo tile, or an IntegrateIT-branded tile (see Choose the tile art).
  • IntegrateIT self-update: the driver checks the IntegrateIT channel and can stage its own next version.

2 The display-only contract

This is the honesty core. IntegrateIT PlayStation 5 cannot know or change anything about the console it represents. It never powers it on, never launches a game, never reads its status. When you select this source, Control4 routes the HDMI OUT binding to the room — video input and audio path switched — nothing more. A driver that claimed power or transport feedback over one HDMI cable would be faking it; this one does not pretend.

3 Power: who turns the console on

The one thing every homeowner asks. The answer, stated plainly:

  • The controller is the power button. Press the PS button on the DualSense and the console wakes; on the console leave Rest Mode available (Settings → System → Power Saving) so the wake is instant instead of a cold boot, and enable Supply Power to USB Ports in Rest Mode so controllers stay charged.
  • HDMI-CEC can help where enabled — a PS5 with Enable HDMI Device Link (Settings → System → HDMI) can wake the display and follow its power. CEC behavior varies by TV and by matrix (many matrices block CEC); treat it as a bonus, never as the design.
  • Why the driver leaves power alone: Sony's network wake rides the Remote Play protocol and needs per-account pairing credentials that expire and break at firmware bumps — a power button that usually fails is worse than no power button. If it can be made reliable, a network wake-on-select ships as an append-only update to this same driver; nothing about today's install would change.

The practical room recipe: leave the console in Rest Mode, tap PlayStation 5 in Watch (room video + audio switch to it), pick up the DualSense and press the PS button. Two presses, and the second one is the one gamers already do.

4 Choose the tile art

The driver ships three tile arts and an Icon Set property to pick between them:

  • Floating Device — the default. The console alone on a transparent background with a soft shadow, the same style as Control4's stock source icons (Apple TV and friends), so it sits natively among them on any Navigator wallpaper.
  • Device Only (No Logo) — the console on the dark IntegrateIT tile.
  • IntegrateIT Branded — the dark tile with the IntegrateIT wordmark added on the large (300 px and up) tiles; below that a wordmark would be unreadable, so smaller branded tiles match Device Only.

Changing the property swaps the live tile files in place, inside the driver's own package, through Control4's File Interface — no re-install, no different .c4z. Two things to know:

  1. Navigator caches are stubborn. After switching, run File ▸ Refresh Navigators; force-close the mobile app or reboot T3–T4 touchscreens if a tile lingers. Same refresh order as any icon change.
  2. The choice survives driver updates. An update re-extracts the package (which resets the tile files to the shipped set), and the driver re-asserts your chosen set on every boot — so the property stays true without anyone remembering it exists.

5 Wire and commission

  1. Physically connect the PlayStation's HDMI output to the room's input — a TV input, an AVR input, or a matrix input (directly, or through an extender). Note which input it lands on.
  2. In Composer Pro, add the driver. Keep the .c4z named exactly as shipped — the icon URLs embed the driver name, and a renamed file (a browser's name (1).c4z) loads fine but shows a blank icon.
  3. In Connections → Video/AV, bind this driver's HDMI OUT to the input from step 1. The binding carries both HDMI video and STEREO audio classes, so the room's audio path follows automatically.
  4. Set the room's Watch experience to include the source. The device shows in rooms as PlayStation 5.
  5. Prove it: select the source in a room, wake the console from the controller, and confirm picture and sound. If the display blanks, see Troubleshoot (EDID).

Field refresh order (Control4 fact #5 — icon caches are stubborn): after any re-release, Update Driver → File ▸ Refresh Navigators → force-close the mobile app / reboot T3–T4 touchscreens. The xmlVersion is bumped on every release so Director notices; the Navigator cache still needs the manual nudge.

6 Read status at a glance

Status shows Idle, changing only to confirm an Icon Set switch (with the Navigator refresh reminder) before the next boot returns it to Idle. The standard IntegrateIT properties (Driver Version, self-update, licensing) behave as they do in every IntegrateIT driver; see Reference. No property on this driver reflects the state of the console, because the driver cannot see it.

7 Troubleshoot methodically

  • Nothing appears in Watch — the source was never bound. Re-check Connections: the HDMI OUT binding must land on the input the console actually feeds.
  • Blank / no-signal on selection — an EDID mismatch. Set that matrix input's EDID to 4K30 or 1080p; a PS5 pushes 4K60/120 with HDR and can out-run a display or a long HDMI run.
  • Game mode features missing (VRR / ALLM / 4K120) — those ride HDMI signaling and survive only if every hop in the routed path supports them (matrix, extender, AVR, display). Route the console through the least processed path the room allows.
  • Picture but no sound — the audio path follows the room's audio endpoint. Verify the room's audio for this source lands on the AVR/amp input that is actually wired.
  • Blank icon in Navigator — the .c4z was renamed, or the Navigator cache is stale. Restore the shipped filename, then run the field refresh order above.
  • Still stuck — contact support with the room name, the matrix model, and the input number.

8 Ownership, privacy, and licensing

Nothing leaves the controller. This driver opens no network connection, holds no credentials, and logs nothing about the console — there is nothing for it to send. Licensing runs in the shared IntegrateIT framework: because the driver has no actuating path, no function is license-gated — a missing or invalid key never disables it. Self-update polls the IntegrateIT channel and can stage the next version for a one-click install in Composer.

L Licensing

This driver is licensed per controller. Each license key locks to one controller's MAC address the first time it activates, exactly like other professional Control4 vendors.

  1. Generate a key for the customer in the IntegrateIT Ops Portal → Licenses.
  2. Paste it into the driver's License Key property in Composer.
  3. On activation the key binds to this controller; the License Status property shows Licensed.

Enforcement. License Enforcement defaults to Lenient (recommended): the driver works the moment it is wired, so you can stage and verify a job before a key is minted, and a paid site keeps running if the license server is ever unreachable. License Status still nags until a key activates. Set it to Strict to disable all control until a valid key binds.

Replaced the controller? Click Unbind in the Ops Portal. The next controller to activate with the key becomes its new home. The driver re-checks on boot and every 12 hours, and keeps working through brief internet outages (it re-validates when the relay is reachable again).

U Automatic updates

The driver checks IntegrateIT for a newer version on boot and once a day. There is no need to re-add the driver. When an update is available the Update Available property shows the new version and the driver fires its Update Available event.

  1. The driver flags Update Available: vX.Y.Z in its properties (or run the Check for Update Now action).
  2. Run the Download & Stage Update action. The new .c4z is fetched onto the controller.
  3. In Composer, right-click the device, then choose Update Driver. Your settings, bindings, and programming are preserved.
Tip: wire the Update Available event to a notification so you know the moment a new build ships.

D Diagnostics and self-test

Every IntegrateIT driver carries two read-only Actions for the field. Run Diagnostics prints a report of what the driver has already observed — version and Lua runtime, license mode and cached activation, update channel and any staged build, every armed timer with its interval, which dealer-supplied properties are still empty, and the last few Status messages. It probes nothing, sends nothing, and changes nothing, so it is safe on a live job. Run Self-Test checks the shared layer itself — string and URL encoding, version comparison, the non-finite number guard, the timer registry, and the persistence store — and ends with SELF-TEST PASS or a per-check failure. It stays local: no network, no device commands.

Neither Action is license gated, on purpose: you reach for them when a site is broken, and the license may be the broken thing. Values are never printed — a key or secret is reported only as set or NOT SET, so the output is safe to paste into a support ticket. Both print to the Lua output window (Composer → the driver's Lua tab).
