# Changelog — IntegrateIT Bond Generic Device

## [0.1.0] - 2026-07-27
- Initial release candidate: dedicated single-device control of a Bond generic device (device type GX) over the Bond Home local API v2 (github.com/bondhome/api-v2).
- Advertised-only control surface: GET /v2/devices/<id> supplies the device's own actions array, and once it is known an action absent from it is refused LOCALLY by name with the reason — nothing reaches the wire. Power On/Off, Toggle Power, and Stop map to TurnOn/TurnOff/TogglePower/Stop; Run Advertised Action reaches any other advertised action by name with an optional numeric argument, and requires the list rather than guessing.
- One device type: a device reporting CF / MS / FP / LT is refused by name and pointed at the IntegrateIT driver that models it (Bond Ceiling Fan, Bond Shade, Bond Fireplace, or the poll-only Bond driver for a light). List Bond Devices annotates every enumerated device with its owning driver.
- Assumed-state contract: a GX device is a learned one-way RF target with no return path, so Bond's /state is Bond's TRACKED BELIEF, not a measurement, and the original hand-held remote bypasses Bond entirely and silently desyncs that belief. POWER is published alongside POWER_ASSUMED and a Power State property that spells "assumed" out loud, in the same one-way honesty register as the Bond Shade, Somfy URTSI II, and ESI R2D7 drivers. Unknown at boot and after any rebind.
- Real push state feedback via the Bond Push UDP Protocol (BPUP) listener on UDP port 30007: keep-alive subscription, \n-delimited JSON frame parsing tolerant of arbitrary datagram boundaries and junk, topic-filtered to this device, and resubscribe before the 125s bridge drop.
- Automatic fallback to hash-gated HTTP polling of /state when BPUP goes silent, with a bounded 429 Retry-After backoff; the Feedback Mode property reports which path is live and why it fell back.
- Publishes POWER, POWER_ASSUMED, and DEVICE_ONLINE with transition-only events (unknown->known baseline adoption is silent); reachability reports the bridge answering, never the RF link.
- BOND-Token header auth (user-supplied, never logged), LAN-only destination guard enforced at the single transport chokepoint so control, polling, AND the boot-time metadata reads are all covered, with an Allow WAN Bond override, and MAC-locked IntegrateIT licensing re-checked at wire-write time on every control path.
- Known limits: one generic device per instance; GX only; power state is assumed and a press on the original remote is undetectable; BPUP needs UDP 30007 reachable or the driver runs poll-only; acceptance on physical hardware is not yet attached to this release.
